# Plotweaver

Конструктор сюжета, блокнот сохранённых планов и генератор стартовых точек для персонажей — три модуля на общем движке (контекст из карточки персонажа, лорбука и истории чата, генерация через основной API или сохранённый профиль подключения).

## 🪶 Plotweaver — конструктор сюжета

Подробный опросник (жанр, тропы, AU, конфликт, романтика, тон, структура и другое) собирает творческий бриф и вместе с контекстом чата отправляет модели запрос на план — от короткого "толчка" с тремя вариантами продолжения до многотомной саги с арками и сценами.

- Чипы с тултипами-подсказками и лимитами выбора
- Предпросмотр итогового промта перед отправкой
- Выбор модели (основной API чата или сохранённый профиль подключения)
- Выбор лорбуков с поиском по списку
- Генерация продолжается в фоне, даже если закрыть окно опросника

## 📓 Sketchbook — блокнот

Хранит сгенерированные планы и персонажей отдельными страницами, привязанными к конкретному чату.

- Markdown-редактор с тулбаром: жирный, курсив, подчёркнутый, зачёркнутый, цветной хайлайт
- Переключение просмотр/редактирование
- Избранное и теги с фильтром
- Отдельные режимы "Сюжеты" и "Персоны"

## 🎭 Alter — генератор персонажей

Компактный модуль: на основе карточки бота и первого сообщения выдаёт стартовую точку для нового персонажа — 10 имён, по 5 вариантов характера и бэкграунда. Не готовые персонажи, а набор заготовок для сборки своего.
